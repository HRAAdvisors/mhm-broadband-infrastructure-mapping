# Maps a raw shapefile (relative to data/raw/) to its converted output
# (relative to data/, matching docs/data-dictionary.md and layers.config.ts).
#
# Format: <raw shapefile>	<output geojson>
# - Tab-separated. Lines starting with # are ignored.
# - Rename your shapefiles to the left-hand names below, OR edit the left
#   column to match whatever you actually have in data/raw/.
# - build-all.sh skips any row whose raw file doesn't exist yet, so you can
#   fill this in / convert incrementally as files show up.
